## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Project Library** | Organize Storyboard Pro projects by production and status |
| **Panel Tracker** | Track panel count progress and key scene completion status |
| **Animatic Versions** | Log animatic versions with timing notes and revision history |
| **Production Notes** | Document director notes and revision requests per scene |
